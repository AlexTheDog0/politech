# Портал аспіранта ВПа-11

Погоджено користувачем: мінімальна односторінкова React-версія для розкладу й контактів.

- React + Vite; українська мова; адаптивна світла сторінка з темно-зеленим акцентом.
- Тижневий розклад, ручний вибір чисельника/знаменника та мовної підгрупи. Початково показувати всіх викладачів іноземної мови; поділ не підтверджений джерелом.
- Блок поточної/наступної пари сьогодні за часом Europe/Kyiv. Це тижневий шаблон: канікули та зміни розкладу не синхронізуються.
- П’ять викладачів з офіційними фотографіями, email, дисциплінами й джерелами; окремий контакт системного адміністратора ІПМТ.
- Кнопки Zoom/ВНС тільки де опубліковані. Фото беруться з офіційних профілів staff.lpnu.ua; у разі помилки — ініціали.
- Посилання на навчальний план 2025 з явним застереженням про непідтверджене застосування до набору 2026.
- Налаштування зберігаються локально. Немає авторизації, сервера або автоматичної синхронізації.
- Перевірки: логіка тижнів, мовний фільтр, часові межі, вихідні, помилки localStorage; збірка; браузер на широкому й мобільному екранах.
