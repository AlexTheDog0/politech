# Мій ІПМТ

Мінімальний React-портал аспіранта ВПа-11, G20 «Видавництво та поліграфія». Розклад осіннього семестру 2026/2027, офіційні фотографії й email п’ятьох викладачів та ІТ-підтримки ІПМТ.

## Запуск

Node.js 22.12+ або 24 LTS.

```sh
npm ci
npm run dev
```

Відкрити адресу, показану Vite (зазвичай http://127.0.0.1:5173).

```sh
npm test
npm run build
npm run preview
```

Готові статичні файли: `dist/`.

## GitHub Pages

Workflow `.github/workflows/deploy.yml` запускає тести, збірку та публікацію після push у `main`. У GitHub → Settings → Pages потрібно обрати Source: GitHub Actions. Шляхи до ресурсів відносні, тому портал працює також у підкаталозі `/politech/`.

Для локальної перевірки підкаталогу:

```sh
npm run build
npm run preview -- --base /politech/
```

Відкрити `http://127.0.0.1:4173/politech/`.

## Дані та налаштування

- `src/data.js`: дисципліни, заняття, контакти, джерела та дата перевірки.
- `src/schedule.js`: фільтрація тижня та поточна/наступна пара сьогодні за Europe/Kyiv.
- `src/components/`: розклад, картки контактів та спільні елементи.
- `public/portraits/`: фото з офіційних профілів staff.lpnu.ua; URL походження є в `src/data.js`.
- `docs/sources.md`: підтвердження джерел та відомі обмеження.

Тип тижня обирається вручну; початково — чисельник. Мовний фільтр початково показує обох викладачів, адже підгрупа користувача не підтверджена. Налаштування зберігаються тільки в localStorage пристрою. Розклад є тижневим шаблоном, без канікул, перенесень і автоматичної синхронізації; для перевірки змін є пряме посилання на офіційний розклад. Навчальний план 2025 позначено як непідтверджений для набору 2026.

Email відкриває поштовий клієнт; кнопка копіювання працює на localhost/HTTPS з дозволеним Clipboard API. Якщо копіювання недоступне, адреса залишається видимою. Шрифт Manrope завантажується з Google Fonts; за відсутності мережі працює системний шрифт.

Публічна версія не зберігає посилання Zoom із кодами доступу: кнопки ведуть до офіційного розкладу університету.
